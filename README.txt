DEPLOY WITH GITHUB PAGES
1. Create a PUBLIC GitHub repository.
2. Upload index.html and wedding-template.png.
3. Settings -> Pages -> Deploy from a branch -> main -> / (root).
4. GitHub provides a public https://USERNAME.github.io/REPOSITORY/ URL.
